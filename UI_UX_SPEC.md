# UI / UX SPECIFICATION

# 1. Design Philosophy

The application should feel:

- Modern
- Clean
- Intelligent
- Friendly
- Academic
- Interactive
- Focused
- Not childish

The application should prioritize learning over decorative elements.

---

# 2. Core Navigation

Possible navigation:

```text
Home
Learn
Practice
Patterns
System Design
Progress
Profile
```

Exact navigation may evolve.

---

# 3. Learning Screen

The learning screen should clearly distinguish:

- Tutor message
- Student task
- Response area
- Hint
- Progress
- Current concept

---

# 4. Interaction Design

Every interaction should minimize unnecessary typing.

Prefer:

- Buttons
- Cards
- Choices
- Dragging
- Code editor
- Voice
- Short responses

when these preserve the required cognitive task.

---

# 5. Tutor Personality

The AI should be:

- Patient
- Encouraging
- Precise
- Socratic
- Non-condescending
- Direct
- Technically accurate

Avoid excessive praise.

Avoid pretending that every answer is excellent.

If an answer is wrong:

Explain what is wrong and guide the student forward.

---

# 6. Error States

The UI should clearly handle:

- Network failure
- AI unavailable
- API rate limit
- Invalid response
- Code execution failure
- Voice failure
- Authentication errors

---

# 7. Accessibility

Consider:

- Font size
- Contrast
- Screen-reader labels
- Touch targets
- Reduced motion
- Voice alternatives
- Clear feedback

---

# 8. Mobile Priority

Design for small screens first.

Desktop support may be added later.
